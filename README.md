📖 About the Course

This course covers the essential concepts of information security, from the foundational principles of confidentiality, integrity, and availability to advanced topics like cryptography and wireless network security.

You will learn how systems are attacked, how malware operates, and how to design and defend networks against real-world threats. Each module builds on the previous one, so it is best to work through them in order.

🎯 What You Will Learn

By the end of this course, you will be able to:

Understand the core principles of information security and the CIA triad
Apply the fundamental security design principles used to build secure systems
Differentiate between authentication methods: password-based, biometric, token-based, and multi-factor authentication
Explain access control models and the difference between authentication and authorization
Identify types of malware, including viruses, worms, trojans, rootkits, and botnets
Recognize common network attacks such as spoofing, denial of service (DoS), man-in-the-middle (MITM), and SQL injection
Use security analysis tools for vulnerability assessment and traffic analysis
Secure network infrastructure with firewalls, proxies, honeypots, and IDS/IPS
Apply system hardening techniques and security baselines
Understand wireless network threats and defenses
Explain the fundamentals of cryptography: symmetric and asymmetric encryption, hashing, and classic and modern ciphers

🚀 How to Use This Repository
Review the modules in order. Later topics build on earlier ones.
Read the slides, then practice. Try the tools and concepts in a safe lab environment.
Take the midterm after Module 5 to check your understanding before moving on to tools, infrastructure, and cryptography.
Revisit Module 1 when you finish. The security principles will make much more sense once you have seen the attacks and defenses.

Suggested pacing: one module per week (about 10 weeks in total).
