#Information Security Course

This is the repository for the Information Security course. It contains all the lecture slides necessary to work through the course from start to finish, covering everything from security foundations to cryptography.

Requirements and Setup

To get the most out of these slides, it's recommended to:

Install Microsoft PowerPoint or LibreOffice Impress to view the .pptx files
Have a basic understanding of computer networks and operating systems
Review each module in order, as later topics build on earlier ones
About the Course

This course covers the essential concepts of information security, from the foundational principles of confidentiality, integrity, and availability to advanced topics like cryptography and wireless network security. You'll learn how systems are attacked, how malware operates, and how to design and defend networks against real-world threats.

What You Will Learn
Understand the core principles of information security and the CIA triad
Learn the fundamental security design principles used to build secure systems
Differentiate between authentication methods, including password-based, biometric, token-based, and multi-factor authentication
Understand access control models and the difference between authentication and authorization
Identify different types of malware, including viruses, worms, trojans, rootkits, and botnets
Recognize common network attacks such as spoofing, denial of service, man-in-the-middle, and SQL injection
Use security analysis tools for vulnerability assessment and traffic analysis
Secure network infrastructure using firewalls, proxies, honeypots, and intrusion detection/prevention systems
Apply system hardening techniques and security baselines
Understand wireless network security threats and defenses
Learn the fundamentals of cryptography, including symmetric and asymmetric encryption, hashing, and classic and modern ciphers
